Projects

A selection of custom hardware we've designed and built.

SignetLine Dongle

A USB hardware token for secure messaging: performs ECDH key exchange and AES-GCM encryption on-device, so the private key never leaves the hardware.

Scalable BMS with Active Balancing

A modular battery management system design with active cell balancing, built to scale across different pack configurations.

USB-C Stackable Power Supply

A compact power supply module with USB-C input, designed to stack for building up modular power rails.

ESP32 Solar Inverter Remote Controller

A custom ESP32-based remote controller for monitoring and controlling a solar inverter.

DC Triac Regulator

A triac-based DC power regulator with a dedicated driver board and an LCD/rotary-encoder UI board for local control.

PoE Power Supply

A Power-over-Ethernet power supply board for powering remote embedded devices over a single Ethernet cable.

Raspberry Pi HAT — Serial, RTC & SD Card

A custom Raspberry Pi HAT adding a serial interface, real-time clock, and SD card storage for embedded data-logging applications.

EVSE Controller

An electric vehicle charging station (EVSE) controller board handling charge control and communication.
